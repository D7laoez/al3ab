# مركز السيارة 🚗

منصة تجارة إلكترونية عربية RTL لبيع قطع غيار السيارات والإكسسوارات والأدوات ومستلزمات الصيانة.

## الموجود حالياً
- واجهة متجر عربية حديثة ومتجاوبة للموبايل والكمبيوتر.
- تصنيفات المنتجات والبحث والتصفية.
- بطاقات منتجات وتقييمات وأسعار.
- سلة شراء محفوظة في LocalStorage.
- تعديل الكميات وحساب الإجمالي.
- نموذج إتمام طلب ودعم الدفع عند الاستلام.
- حساب مستخدم مبدئي.
- SEO metadata أساسي وواجهة RTL.
- بنية جاهزة للتوسع إلى Backend وقاعدة بيانات ودفع إلكتروني.

## التشغيل
افتح `index.html` مباشرة، أو استخدم أي static hosting مثل GitHub Pages / Cloudflare Pages / Vercel.

## المرحلة التالية للإطلاق التجاري
1. ربط Supabase للمستخدمين والمنتجات والمخزون والطلبات.
2. لوحة تحكم الإدارة وإدارة المنتجات والأسعار والمخزون والطلبات.
3. ربط صور المنتجات من Storage.
4. حالات الطلب والشحن والتتبع.
5. بوابات الدفع العراقية عند توفر بيانات التاجر.
6. كوبونات وعروض ومفضلة وحفظ سيارات العملاء.
7. نظام توافق القطعة مع الشركة/الموديل/المحرك.
8. إشعارات WhatsApp/SMS والبريد.
9. تحليلات المبيعات والأرباح والمخزون.
10. اختبارات آلية وCI/CD وأمن وصلاحيات.

> المشروع مبني ليكون أساس متجر سيارات حقيقي، وليس صفحة هبوط فقط.
