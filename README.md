# مركز السيارة 🚗

منصة تجارة إلكترونية عربية RTL موجهة للسوق العراقي لبيع قطع غيار السيارات والإكسسوارات والأدوات ومستلزمات الصيانة.

## ما تم بناؤه
- متجر عربي RTL متجاوب للموبايل والكمبيوتر.
- بحث حسب اسم القطعة والفئة والماركة.
- تصنيفات ومنتجات وفرز حسب السعر والتقييم.
- تفاصيل المنتج + المخزون + الماركة + توافق مبدئي.
- سلة شراء محفوظة محلياً مع تعديل الكميات.
- مفضلة محفوظة محلياً.
- مساعد اختيار القطعة حسب ماركة السيارة والفئة.
- Checkout عراقي: الاسم، الهاتف، المحافظة، المنطقة، العنوان، طريقة الدفع.
- حساب شحن حسب المحافظة العراقية.
- إنشاء رقم طلب وتخزين الطلبات محلياً للتجربة.
- شاشة طلباتي والمفضلة.
- واجهة حساب مبدئية جاهزة للربط بالمصادقة.
- Responsive mobile navigation.
- SEO metadata وRTL وواجهة عربية بالكامل.

## Backend foundation
يوجد ملف `supabase/schema.sql` يحتوي بنية قاعدة بيانات قابلة للإطلاق تشمل:
- المستخدمين والأدوار Admin/Customer.
- المنتجات والفئات والماركات والصور.
- السيارات وتوافق القطع مع الموديل/السنة/المحرك.
- العناوين والشحن حسب المحافظة.
- الطلبات وبنود الطلب وحالات الدفع والشحن.
- الكوبونات والمفضلة والتقييمات.
- Audit logs.
- Row Level Security وصلاحيات الإدارة.

**مهم:** لا يوجد أي مفتاح Supabase أو بيانات حساسة داخل المستودع. يجب إنشاء مشروع Supabase مخصص للمتجر وربط متغيرات البيئة قبل تفعيل الـBackend الحقيقي.

## التشغيل الحالي
يمكن فتح `index.html` مباشرة، أو استضافته على GitHub Pages / Cloudflare Pages / Vercel. الوظائف المحلية (السلة والمفضلة والطلبات التجريبية) تعمل بدون Backend.

## الطريق إلى الإطلاق التجاري
1. إنشاء مشروع Supabase مخصص للمتجر وتشغيل `supabase/schema.sql`.
2. تحويل الكتالوج التجريبي إلى جدول `products` ورفع الصور إلى Storage.
3. تفعيل Supabase Auth وربط حسابات العملاء.
4. بناء لوحة Admin كاملة: المنتجات، الفئات، الماركات، المخزون، الطلبات، العملاء، الكوبونات، الشحن والتقارير.
5. جعل إنشاء الطلب Transactional مع التحقق من الأسعار والمخزون على الخادم وعدم الوثوق بقيم العميل.
6. إضافة بوابة دفع إلكتروني عراقية بعد توفر حساب تاجر وAPI موثوق.
7. إضافة إشعارات الطلب عبر WhatsApp/SMS/Email.
8. إضافة اختبارات، CI/CD، مراقبة الأخطاء، النسخ الاحتياطي وسياسات الأمان.

## مبدأ أمني
السعر النهائي والمخزون وطريقة احتساب الشحن يجب أن تُعاد حسابها في Backend قبل تثبيت أي طلب. واجهة المتصفح ليست مصدر ثقة.
