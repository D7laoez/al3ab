# مركز السيارة 🚗

منصة تجارة إلكترونية عربية RTL موجهة للسوق العراقي لبيع قطع غيار السيارات والإكسسوارات والأدوات ومستلزمات الصيانة.

## الحالة الحالية
تم تحويل المشروع من صفحة متجر تجريبية إلى أساس منصة تجارة إلكترونية كاملة قابلة للربط ببيئة إنتاج.

### المتجر
- واجهة عربية RTL متجاوبة للموبايل والكمبيوتر.
- بحث وفلاتر وتصنيفات وفرز.
- بطاقات منتجات مع السعر، الخصم، التقييم، المخزون والماركة.
- سلة شراء، تعديل كميات، مفضلة.
- مساعد اختيار القطعة حسب السيارة والفئة.
- Checkout عراقي: الاسم، الهاتف، المحافظة، المنطقة، العنوان، طريقة الدفع.
- احتساب شحن حسب المحافظة.
- رقم طلب، تتبع، طلباتي، المفضلة.
- SEO metadata وManifest وrobots.

### الإدارة
- `admin.html` لوحة إدارة محمية بــSupabase Auth + دور `admin`.
- مؤشرات الطلبات والمبيعات والمنتجات والمخزون المنخفض.
- إدارة حالات الطلبات.
- عرض وتعديل المخزون.
- إضافة منتجات أولية من لوحة الإدارة.

### Backend / Supabase
`supabase/schema.sql` يحتوي:
- profiles وroles.
- categories / brands / products / product_images.
- vehicles وproduct_compatibility.
- addresses وshipping_rates.
- orders وorder_items.
- coupons / favorites / reviews / audit_logs.
- Row Level Security.
- دالة `create_guest_order(jsonb)` لإعادة حساب السعر والشحن والتحقق من المخزون داخل PostgreSQL وتنفيذ خصم المخزون بشكل transactional.

`supabase/seed.sql` يحتوي بيانات تجريبية للمنتجات والماركات.

### الجودة
- `package.json` لأوامر الفحص والاختبارات.
- `tests/store.test.js` لاختبارات منطق الهاتف والشحن والإجمالي والسلة.
- `.github/workflows/ci.yml` لفحص JavaScript وتشغيل الاختبارات مع كل Push وPull Request.

## تشغيل المتجر على Windows مع تحديث تلقائي
هذه الطريقة مناسبة للتجربة اليومية على الحاسبة:

1. ثبّت **Git for Windows** و **Node.js 20+**.
2. افتح PowerShell في المكان الذي تريد حفظ المشروع داخله.
3. نفّذ:
```powershell
git clone https://github.com/D7laoez/al3ab.git
cd al3ab
```
4. شغّل:
```powershell
.\ابدأ-المتجر.bat
```

سيحدث التالي تلقائياً:
- يسحب آخر نسخة من `main`.
- يشغل الموقع محلياً على `http://localhost:3000`.
- يفتح المتصفح.
- يراقب GitHub كل 3 ثوانٍ.
- عند وصول Commit جديد من GitHub يسحب التعديل تلقائياً.
- `live-server` يعيد تحميل الصفحة تلقائياً عندما تتغير الملفات محلياً.

**مهم:** إذا كانت لديك تعديلات محلية غير محفوظة في Git، فإن المراقب يتوقف عن السحب مؤقتاً حتى لا يكتب فوق شغلك.

## تشغيل يدوي


## تفعيل Backend الحقيقي
1. أنشئ مشروع Supabase مستقل لهذا المتجر.
2. نفّذ `supabase/schema.sql` ثم `supabase/seed.sql`.
3. انسخ `config.example.js` إلى `config.js` وضع Supabase URL وAnon Key فقط. لا تضع Service Role Key في المتصفح.
4. أنشئ مستخدم الإدارة من Supabase Auth ثم اجعله `admin` في `profiles` وفق التعليق الموجود في الـSQL.
5. أضف صور المنتجات إلى Storage واربطها بجدول `product_images`.

## ملاحظات الإطلاق
الدفع عند الاستلام هو المسار الافتراضي. بوابات الدفع الإلكترونية العراقية وWhatsApp/SMS تحتاج بيانات التاجر وواجهات API حقيقية، لذلك لم يتم اختراع مفاتيح أو تكاملات وهمية.

قبل الإطلاق التجاري يجب أيضاً:
- وضع الدومين الحقيقي في `robots.txt` وcanonical.
- مراجعة سياسات الخصوصية والشحن والاسترجاع.
- ضبط CORS/Storage policies حسب الدومين.
- تشغيل مراقبة أخطاء ونسخ احتياطية لقاعدة البيانات.
- اختبار الطلبات والمخزون تحت التزامن.
